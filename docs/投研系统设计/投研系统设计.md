核心设计决策

1. 估值拆成两张表（重要）

以前 fundamental_snapshots 把 PE/PB 和 ROE/现金流混在一起——PE 每天随价格变，ROE 每季才更新。现在拆开：
- research_valuation_daily → 每日价格驱动，算 PE 历史分位
- research_fundamental_detail → 季报后更新，存真实财务数据，带 data_period = "2024Q4"

2. data_period 字段

fundamental_snapshots 和 research_fundamental_detail 都加了 data_period（如 2024Q4, 2024H1），防止用快照日期反推数据来自哪个报告期。

3. research_announcements 作为事件总线

公告先落地（is_nlp_processed=False），NLP pipeline 异步处理后更新 direction/magnitude/summary，同时触发 capital_cycle_snapshots 和 sentiment_events 的写入。

4. research_report_metadata 存评分快照

每次生成报告时，把五截面评分打快照进去，这样即使后续数据更新，也能回溯"这份报告生成时的市场状态"。
