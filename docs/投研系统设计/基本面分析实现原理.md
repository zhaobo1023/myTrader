  基本面分析 tab -> report_type='fundamental' -> 走的是
  FiveStepAnalyzer（五步法），即：

  2. 华夏银行会被识别为 BANK_CONFIG，五步法的 Prompt 全部替换为银行专属版本
  3. needs_bank_indicators=True 会触发采集银行专属数据（NPL、NIM、拨备、诊断信号等）
  4. 最终输出是 Markdown 研报（ReportBuilder.build_fundamental_only()）
