# Claude Financial Services 插件 x A股投资 - 知识框架与实践指南

## 一、插件与投资决策的定位

插件是工具，核心价值是**帮你结构化思考**——把模糊的直觉变成可追溯、可验证的分析。

投资决策的完整流程：
```
宏观环境判断 → 行业选择 → 个股筛选 → 估值定价 → 仓位管理 → 持续跟踪
     ^                                                              |
     |______________________ 观点更新（/thesis）______________________|
```

| 环节 | 对应工具 |
|---|---|
| 宏观判断 | `/morning-note` + myTrader macro_data |
| 行业选择 | `/sector` + myTrader sw_rotation |
| 个股筛选 | myTrader multi_factor / xgboost |
| 估值定价 | `/comps` + `/dcf` |
| 仓位管理 | myTrader risk_manager |
| 持续跟踪 | `/thesis` + `/catalysts` |

核心方法论：**量化筛选 + 基本面验证**
- 用 myTrader 的因子/策略选出候选股
- 再用插件的 `/comps`、`/earnings` 做深度验证
- 用 `/thesis` 为每只持仓建立投资逻辑卡片，每季更新

## 二、财务报表分析

### 参考教材

- **主力教材**：《财务报表分析与证券估值》（Stephen Penman）— CFA 体系级，财务分析 + 估值定价一体化
- **辅助参考**：《手把手教你读财报》（唐朝）— A 股财报实操，入门快

### 三表联动核心

| 报表 | 核心看什么 | A 股注意点 |
|---|---|---|
| **利润表** | 营收增速、毛利率趋势、费用率变化 | 区分内生增长 vs 并购驱动 |
| **资产负债表** | 资产结构、负债率、商誉、应收账款 | 高商誉公司暴雷多（游戏、影视） |
| **现金流量表** | 经营现金流 vs 净利润的匹配度 | "利润有水分"的信号灯 |

关键认知：**净利润 ≠ 赚到钱**，经营现金流才是真金白银。

myTrader 数据支撑：
- `trade_stock_financial` — 汇总级财务数据（营收/净利/ROE/毛利率等）
- `financial_income` — 利润表明细（采集完成后可用）
- `financial_balance` — 资产负债表明细（采集完成后可用）
- `financial_cashflow` — 现金流量表

### 财报季节性

```
1-4月：年报密集期（4月30日截止）
7-8月：中报密集期（8月31日截止）
10月：三季报（10月31日截止）
全年：公告、增减持、股权激励等持续披露
```

## 三、估值方法论

### 常用估值方法

| 方法 | 适用场景 | 局限性 |
|---|---|---|
| **PE（市盈率）** | 成熟盈利企业，行业对比 | 周期股 PE 低位反而是顶部 |
| **PB（市净率）** | 银行、地产等重资产行业 | 轻资产公司（软件）PB 意义不大 |
| **PS（市销率）** | 亏损的成长期公司 | 不反映盈利能力 |
| **DCF** | 现金流可预测的公司 | 对假设极度敏感 |
| **PEG** | 成长股估值 | 增速不可靠时失效 |

### DCF 关键参数（A 股调整）

| 参数 | 美股默认 | A 股调整 |
|---|---|---|
| Risk-free Rate | US 10Y (~4.3%) | 中国 10Y 国债 (~1.6-1.8%) |
| Beta 基准 | S&P 500 | 沪深300 |
| Equity Risk Premium | 4-6% | 5-7%（新兴市场溢价） |
| Cost of Debt | 美联储基准利率 | LPR（贷款市场报价利率） |
| Tax Rate | 21% (US) | 25%（高新技术企业 15%） |
| Terminal Growth | 2-3% | 4-5%（中国长期 GDP 增速） |

核心认知：
- 估值是**概率区间**，不是精确数字
- DCF 的价值在于理解决定价值的**关键变量**，而非精确价格
- 改变 WACC 或终端增速 1%，结果可能差 20%+

myTrader 数据支撑：`trade_stock_valuation_factor`（PE_TTM, PB, PS_TTM, 市值）

## 四、行业与竞争分析

### 分析框架

- **行业生命周期**（导入→成长→成熟→衰退）→ 决定估值方法
- **竞争格局**（CR3/CR5 集中度）→ 决定龙头溢价
- **商业模式**（to B/to C/to G、recurring vs one-off）→ 决定收入可预测性

### A 股行业特色指标

| 行业 | 关键指标 |
|---|---|
| 银行 | ROE、不良率、净息差、成本收入比 |
| 房地产 | 合约销售、预收账款、净负债率 |
| 新能源 | 产能、产能利用率、单瓦成本 |
| 消费 | 门店数、同店增长、渠道毛利率 |
| 医药 | 在研管线阶段、商业化产品数、医院覆盖 |
| 互联网 | MAU、ARPU、抽佣率、GMV |
| 软件/信创 | 人均产出、续约率、许可证 vs 服务收入占比 |

### A 股行业特殊性

| 类型 | 特点 | 典型行业 |
|---|---|---|
| **政策驱动型** | 政策拐点比财报更重要 | 新能源、信创、半导体 |
| **周期型** | PE 低时卖出、PE 高时买入（反直觉） | 钢铁、煤炭、航运 |
| **消费型** | 品牌力和渠道力是核心 | 白酒、调味品、家电 |
| **科技型** | 技术迭代风险大，护城河易变 | 软件aaS、芯片设计 |

myTrader 数据支撑：`sw_industry_valuation`、`trade_sector_strength_daily`

## 五、投资思维框架

### 观点构建与维护

专业投资者和散户最大的区别：**每个持仓都要有明确的投资逻辑**

- 为什么买？（核心逻辑 1-2 句话）
- 什么情况下卖？（止损条件、逻辑破坏条件）
- 定期用新数据检验逻辑是否成立
- 区分"观点变了"和"价格变了" — 跌了不等于逻辑错了

### 风险思维

| 风险类型 | 说明 |
|---|---|
| **认知风险** | 不了解的行业/公司/工具，不碰 |
| **集中度风险** | 单一行业/主题超 30% 要警惕 |
| **流动性风险** | microcap 策略天然面临停牌/跌停卖不出 |
| **政策风险** | A 股特有，教育/互联网/地产前车之鉴 |
| **估值风险** | 买入时的估值水平决定未来收益（高位追涨是最大风险源） |

### 数据交叉验证

不要只信一个数据源：

| 场景 | 验证方式 |
|---|---|
| 财务数据 | Tushare vs AKShare vs 巨潮公告原文 |
| 估值数据 | 实时行情计算 vs Tushare daily_basic |
| 行业分类 | 申万分类 vs 证监会分类 |

## 六、A 股市场特有认知

| 特征 | 影响 |
|---|---|
| 散户占比高 | 情绪波动大，技术面和资金面信号有效性强 |
| T+1 + 涨跌停 | 流动性风险，止损执行困难 |
| 政策市 | 行业政策可直接改变基本面 |
| 披露质量参差 | 财务数据需交叉验证 |
| 北向资金 | 外资风向标作用 |
