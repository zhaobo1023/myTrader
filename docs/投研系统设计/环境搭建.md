> with gemini
> 备注：为了节省成本，发现网络带宽是一个比较消耗money的东西

2026-03-21

Mac 搭配 Parallels 运行 Windows，再加上 Docker 做服务端容器化，这是目前做量化投研非常经典且极其高效的“单兵作战”拓扑结构。这套架构能完美兼顾 Windows 的生态（跑 QMT）和 Unix/类 Unix 的开发体验。

对于经常做服务端架构设计和开发的人来说，搞定这套本地多端互联的网络拓扑其实非常顺手。以下是针对你这套多 Mac 硬件环境的本地数据库搭建指南：

## 1. 核心运行方式：强烈建议使用 Docker

在作为主服务器的那台 Mac 上，**绝对推荐使用 Docker（或 OrbStack，在 Mac 上比 Docker Desktop 更轻量且网络穿透更好）来运行 MySQL**。

这样可以保证宿主机环境的纯净，而且未来你想把数据库打包迁移到阿里云时，直接迁移挂载的数据卷或重放一套 SQL 脚本即可，毫无阻力。

## 2. 数据存储：必须使用本地数据卷挂载 (Volume Mapping)

Docker 容器是无状态的，如果你不把数据挂载到 Mac 的本地磁盘，容器一旦重启或销毁，你的 300 万条 K 线数据就灰飞烟灭了。你需要通过 Docker 的 `volumes` 指令，把 Mac 宿主机的某个目录（比如 `~/quant_data/mysql`）映射到容器内的 `/var/lib/mysql`。

你可以直接在主 Mac 上新建一个 `docker-compose.yml` 文件：

YAML

```
version: '3.8'
services:
  mysql-quant:
    image: mysql:8.0
    container_name: quant-mysql
    restart: always
    ports:
      - "3306:3306" # 映射到宿主机的 3306 端口，对外提供服务
    environment:
      MYSQL_ROOT_PASSWORD: your_strong_password
      MYSQL_DATABASE: quant_db
    volumes:
      - ~/quant_data/mysql/data:/var/lib/mysql # 核心：数据持久化到 Mac 本地磁盘
      - ~/quant_data/mysql/conf:/etc/mysql/conf.d # 配置文件映射
    command: 
      - --character-set-server=utf8mb4
      - --collation-server=utf8mb4_unicode_ci # 确保完美支持A股的中文股票名称
```

在文件所在目录执行 `docker-compose up -d`，你的本地数据库就跑起来了，数据会实打实地存在你的 Mac 硬盘上。

## 3. 多端连接与对外提供服务 (网络拓扑设计)

你有三类“客户端”需要连接这个 MySQL：Parallels 里的 QMT、主 Mac 本地的回测代码、以及其他 Mac 笔记本。你需要打通局域网（LAN）：

**第一步：固定主 Mac 的局域网 IP**

在你的家庭路由器设置里，找到 DHCP 静态 IP 分配（地址保留），把你这台运行 MySQL 的主 Mac 的 MAC 地址绑定一个固定的局域网 IP（例如 `192.168.1.100`）。这是整个系统的基石，防止路由器重启后 IP 变动导致所有连接失效。

**第二步：打通 Parallels (Windows) -> 主 Mac (MySQL)**

Parallels 的网络设置通常有两种模式，这里决定了 QMT 怎么连数据库：

- **共享网络 (Shared Network - 推荐)**：Windows 相当于在一个子网里。你可以直接在 Windows 中通过主 Mac 的局域网 IP (`192.168.1.100`) 以及端口 `3306` 来连接 MySQL。
    
- **桥接网络 (Bridged Network)**：Windows 会像一台独立的实体电脑一样直接连入你家的路由器，获取一个独立的 `192.168.1.x` 的 IP。同样，直接用 `192.168.1.100:3306` 连接即可。
    

**第三步：打通其他 Mac -> 主 Mac (MySQL)**

只要其他闲置的 Mac 连入同一个家庭 Wi-Fi 或有线网络，在代码里直接将数据库 host 配置为 `192.168.1.100`，端口 `3306` 即可。

**第四步：数据库权限配置**

默认情况下，MySQL 的 root 用户可能只允许 `localhost` 登录。你需要进入 MySQL，创建一个允许局域网访问的账号：

SQL

```
CREATE USER 'quant_user'@'%' IDENTIFIED BY 'your_password';
GRANT ALL PRIVILEGES ON quant_db.* TO 'quant_user'@'%';
FLUSH PRIVILEGES;
```

这里的 `'%'` 意味着允许任何 IP（在你的局域网内）连接，这是实现多端同步和跨机器调用的关键。
