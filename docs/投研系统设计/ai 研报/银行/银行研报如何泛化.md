  银行业分析的核心方法论框架

  一、为什么银行和其他行业不同

  银行有三个独特性，决定了分析框架必须不同：

  1. 利润可以被合法"制造"
  拨备是可以主动调节的。拨备覆盖率从461%降到373%，利润增了多少？是经营改善还是财务操作
  ？普通行业的利润没有这个维度。

  2. 净资产是核心约束，不是结果
  资本充足率决定了贷款能放多少。ROE高但资本不够，就不能成长。银行的成长性和盈利性是被资
  本约束捆绑的，这是制造业、消费品完全没有的逻辑。

  3. 资产质量是滞后的定时炸弹
  今天的利润是真实的，但藏在贷款里的损失要2-3年后才浮出水面。NPL率是滞后指标，逾期贷款
  趋势才是领先指标。

  ---
  二、银行分析的数据层级

  第一层（核心必看，缺了就是盲人分析）
  ├── 官方NPL率 + 拨备覆盖率
  ├── NIM趋势
  ├── 归母净利润 + YoY
  └── 核心一级资本充足率

  第二层（质量判断，分辨真假）
  ├── NPL率2 = (逾期90天+ + 重组贷款) / 总贷款
  │   → 判断不良认定是否严格
  ├── 拨备比趋势 = 拨备余额 / 总贷款
  │   → 分离"拨备释放"对利润的贡献
  ├── 营业利润 vs 归母净利润 剪刀差
  │   → 判断税收/少数股东是否在扭曲利润表
  └── 股东权益增长 vs (净利润 - 分红) 差值
      → OCI浮亏，债券估值是否在侵蚀净资产

  第三层（深度验证，有则更好）
  ├── 逾期贷款期限结构（3月内/3月-1年/1-3年/3年+）
  ├── 公允价值变动损益绝对值
  ├── 信用减值损失 vs 贷款规模（信用成本）
  └── 存款付息率趋势（负债成本）

  ---
  三、必答的六个强制问题

  这是任何银行报告必须回答的问题，不是"发现了几个有趣的数据"，而是强制性的检查清单：

  Q1：不良是真实的吗？
  检查：NPL率2 vs 官方NPL率
  - NPL率2 < 官方NPL率 → 认定严格，可信
  - NPL率2 > 官方NPL率 + 1ppt → 存在隐藏不良，危险
  - NPL率2 N/A → 明确标注数据缺失，结论保留

  Q2：利润是真实的，还是靠拨备撑的？
  检查：拨备比变化 × 总贷款 = 拨备释放量
  - 若拨备释放 > 净利润增量的50% → 利润主要靠财务操作
  - 若营业利润增速 << 归母净利增速 → 还有税收/少数股东扭曲
  结论：分解利润增速来源

  Q3：净资产是否被隐性侵蚀？
  检查：理论权益 = 期初权益 + 净利润 - 分红
        OCI差值 = 实际权益 - 理论权益
  - 若OCI差值 > 净利润5% → 债券浮亏在侵蚀净资产，PB被低估
  - 若OCI差值持续为负 → 利率风险暴露需警惕

  Q4：资本够用吗？
  检查：贷款增速 vs 内生资本补充速度（≈ROE × (1 - 派息率)）
  - 若贷款增速 > 内生补充速度 × 3 → 1-2年内需要外部补充资本
  - 若核心一级距监管底线 < 50bps → 高度警惕

  Q5：息差是在稳住还是在塌陷？
  检查：NIM趋势 + 负债成本趋势
  - 若NIM降速放缓 AND 存款付息率下降 → 底部临近
  - 若NIM快速下降 AND 负债成本刚性 → 商业模式受压

  Q6：市场定价了什么，没定价什么？
  检查：PB × BVPS → 隐含股价 vs ROE vs Ke
  - 隐含ROE = PB × Ke / (1 + g) (反推)
  - 若实际ROE >> 隐含ROE → 估值低估
  - 附加：股息率 vs 国债收益率

  路径C：评分卡体系（最完整，工程量大）

  给每个维度设定评分（0-10分），加权得到综合评级：

  资产质量（30%权重）= f(NPL率2偏差, 逾期趋势, 拨备缓冲)
  盈利质量（25%权重）= f(拨备贡献比, 营业利润剪刀差, OCI差值)
  资本充足（20%权重）= f(核心一级距监管底, 贷款增速/资本生成比)
  息差韧性（15%权重）= f(NIM趋势斜率, 负债成本趋势)
  估值安全（10%权重）= f(PB vs 隐含ROE偏差, 股息率vs国债)

  LLM的角色从"发现数据"变成"填写评分卡 + 解释评分依据"，输出高度一致且可对比。

  ---
  五、框架背后的思维模式

  最底层的方法论是：银行分析的核心是把一个数字拆成"可信部分"和"操作部分"。

  报告净利润 = 真实经营利润 + 拨备释放 + 税收节约 + OCI影响
  报告净资产 = 真实资产价值 + OCI浮盈浮亏
  报告NPL率  = 真实不良 × 认定严格系数

  当AI和分析师看到293亿净利润，专业分析师看的是"拆分后每个部分有没有变好"，普通LLM看的
  是"293亿是个大数字，增速不错"。这就是Flitter方法的本质。

  把这个拆解逻辑编码到系统里，就能让AI复现专业分析师的思维，而不是"看到好数字就说好"。
