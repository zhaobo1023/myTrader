# myTrader 介绍

> 版本: v1.0 | 日期: 2026-04-14

---

## 一、平台定位

myTrader Web 是一个面向个人和小团队的量化投资研究平台，覆盖从市场监控、行业轮动、个股研究、策略选股，到组合管理的完整投研链路。

核心设计原则：**数据驱动 + AI 辅助 + 流程闭环**。

## 三、各模块详细说明

### 3.1 自选股仪表板 `/dashboard`

**用途**: 快速掌握关注个股的最新技术状态，是每日开盘前的第一眼面板。

**核心功能**:
- 搜索添加股票到自选股列表
- 每支股票展示 5 维度扫描结果、综合评分（0-10 分）、风险等级
- 风险等级三档：RED（警示）/ YELLOW（注意）/ GREEN（正常）
- 点击卡片直跳个股分析页

**如何看评分**:
- 评分 7-10: 技术形态强势，信号积极
- 评分 4-6: 中性，需结合其他维度判断
- 评分 0-3: 技术走弱或出现风险信号

**操作流程**:
```
搜索股票名称或代码 -> 点击搜索结果添加 -> 卡片自动展示最新扫描结果
```

### 3.2 行情看板 `/market`

**用途**: 两个视角看市场 -- 宏观大势 + 个股相对强度。

#### 标签1: 市场概览

展示以下指标组：

| 分组 | 指标 | 说明 |
|------|------|------|
| 宏观脉冲 | QVIX / 北向资金 / M2同比 / 制造业PMI / AH溢价 | 判断市场整体温度 |
| 市场结构 | 换手率 / 股债利差（A股+美股） | 资金活跃度和配置性价比 |
| 风格轮动 | 大盘/小盘 / 成长/价值 | 当前市场偏好哪种风格 |
| 股息追踪 | 股息利差 / 40日超额收益 / A股港股相对表现 | 红利策略参考 |
| 估值锚 | 5年均线偏离 / 权益基金3年滚动收益 | 判断当前估值相对历史位置 |

每个指标旁边都有**信号标签**（如超买/超卖/中性），并附有小型走势图。

#### 标签2: 个股行情

- **K线查询**: 输入股票代码或名称，选时间范围，查看 OHLCV 日线数据表格
- **RPS 排名**: 查看相对价格强度排名，可切换 20/60/120/250 日周期
  - RPS 反映的是一支股票在全市场中的价格表现分位
  - RPS > 80 通常是强势股筛选的起点
  - 点击 RPS 表中的股票可直接跳转查看该股 K 线

### 3.3 个股分析 `/stock`

**用途**: 对单只股票做全方位深度研究，是平台最核心的研究工具。

页面左侧是已分析股票的卡片列表，支持按市场（沪/深）、市值（大/中/小盘）筛选，也可直接搜索。

点击股票进入分析页，分 5 个标签：

#### 标签1: 一页纸研究

- 基于 RAG（检索增强生成）+ 大语言模型，综合基本面和技术面生成简洁研究结论
- 输出包括：短期/长期相对价值判断、主要风险、投资建议
- 支持查看最近 10 份历史版本
- 生成需要 1-3 分钟，进度实时显示

**如何看结果**:
- 结论分「机会/观望/回避」三类
- 重点关注「主要风险」部分，识别需要跟踪的变量

#### 标签2: 综合分析（五截面）

- HTML 格式的完整研报
- 覆盖五个分析截面（行业地位、财务质量、估值、技术面、催化剂）
- 支持在新标签页打开完整报告

#### 标签3: 技术面分析

- 展示最近 3 日的技术扫描报告
- 每份报告包括：综合评分、信号等级（RED/YELLOW/GREEN）、MA 形态描述
- 展开可看详细信号列表和关键指标数值
- 可跳转查看完整 HTML 技术报告

**如何看技术面报告**:
- **均线形态**: MA5 > MA20 > MA60 > MA250 是多头排列
- **MACD 信号**: 金叉/死叉、柱状图由负转正
- **RSI**: 超过 70 超买，低于 30 超卖
- **量比**: 放量 > 1.5，缩量 < 0.8

#### 标签4: 基本面分析

- 五步法深度研报（Markdown 格式）
- 步骤：行业格局 -> 竞争壁垒 -> 财务分析 -> 估值 -> 催化剂

#### 标签5: 个股动态

- 公司公告和重大事件（功能开发中）

### 3.4 舆情监控 `/sentiment`

**用途**: 实时感知市场情绪，用于择时参考和风险预警。

#### 标签1: 大盘总览

一屏展示市场关键温度计，覆盖：
- 情绪温度（恐慌/贪婪区间）
- 市场趋势方向
- 风格偏好
- 股债性价比

#### 标签2: 恐慌指数

| 指标 | 来源 | 含义 |
|------|------|------|
| QVIX | A股波动率指数 | A股隐含波动率，高=恐慌 |
| OVX | 原油波动率 | 大宗商品风险情绪 |
| GVZ | 黄金波动率 | 避险情绪 |
| 美债10年收益率 | 美国国债 | 无风险利率参考 |
| Fear & Greed Score | 综合合成 | 0-100，<25 极度恐慌，>75 极度贪婪 |

**使用建议**: QVIX 突然放大（相比近期均值 +50% 以上）往往是短线底部区域。

#### 标签3: 新闻舆情

- 聚合 A 股相关新闻
- 对每篇新闻进行情感标注（正面/负面/中性）
- 可按个股代码筛选

#### 标签4: 事件信号

- 检测特定关键词的市场事件（如回购、重组、增持、解禁）
- 每个事件带信号评级

#### 标签5: 预测市场

- Polymarket 相关预测合约数据
- 筛选关键词和最低成交量过滤噪音

### 3.5 行业分析 `/industry`

**用途**: 行业轮动的量化工具，用于判断哪些行业正在走强、哪些在降温。

#### 模块1: ETF 对数乖离率

监控 12 只申万一级行业 ETF 的**对数乖离率（log_bias）**。

**什么是对数乖离率**:
- log_bias = ln(当前价格) - ln(N日均价)
- 反映价格偏离均值的程度，正值=偏高，负值=偏低

**信号判断**:

| 信号 | 含义 | 操作参考 |
|------|------|---------|
| 过热 | log_bias 显著偏高，均值回归压力 | 减仓或观望 |
| 突破 | 价格突破均线向上 | 关注趋势延续 |
| 回调 | 短期回调但趋势未破坏 | 可能是加仓窗口 |
| 急跌 | 价格快速下跌偏离均值 | 谨慎，等稳定信号 |
| 正常 | 在均值附近波动 | 无特殊信号 |

每个 ETF 可展开查看 120 日走势图。

#### 模块2: 每周横截面排名

每周五收盘后自动生成申万 31 个行业的综合排名。

**4 个评分维度**:
- **过热**: 价格相对估值偏高程度
- **上升**: 近期趋势动量
- **启动候选**: 底部形态，可能开始启动
- **退潮**: 已进入下降趋势

**如何使用**:
1. 优先关注「上升」维度排名靠前 + 「过热」程度低的行业
2. 「启动候选」高分行业可以开始建仓观察
3. 「退潮」高分行业谨慎持仓

#### 模块3: 行业选股

在目标行业内通过 RPS 阈值筛选个股，支持按以下排序：
- RPS250（1年相对强度）
- RPS120（半年相对强度）
- RPS20（近月相对强度）
- 斜率（RPS 趋势加速度）

筛选结果可一键加入候选池。

### 3.6 候选池 `/candidate-pool`

**用途**: 股票从「感兴趣」到「建仓」之间的管理工具，是投研工作流的核心节点。

**三种来源**:
- 手动添加（搜索后直接加入）
- 策略选股结果（一键加入）
- 行业选股结果（一键加入）

**每支股票的展示信息**:
- 名称、代码、状态、来源、加入日期
- 最新价格和涨跌幅
- RPS250
- 最新技术信号（实时更新）

**状态管理**:

| 状态 | 含义 |
|------|------|
| 观察中 | 默认状态，纳入每日监控 |
| 重点关注 | 近期可能操作 |
| 已排除 | 暂时排除但不删除，留存记录 |

**展开查看详情**:
- 加入时的快照：加入时的 RPS、价格、信号
- 近 30 日监控记录：每日价格、RPS、信号变化
- 备注编辑

**自动监控**:
- 盘后可手动触发「运行监控」，更新所有候选股的最新信号
- 支持推送到飞书 Webhook（需配置）

### 3.8 策略选股 `/strategy`

**用途**: 一键运行预设量化选股策略，获取信号股票列表。

**每个策略卡片包含**:
- 策略名称和逻辑描述
- 参数说明
- 风险提示（danger/warning/info 三级）
- 执行按钮（自动感知「今日已完成」状态）
- 最近执行记录（日期、状态、信号数量、大盘状态）

**执行结果查看**:

展开执行记录，查看信号股票表格：

| 字段 | 说明 |
|------|------|

| 信号类型 | 具体触发的技术信号 |
| RPS | 相对价格强度分位 |
| 收盘价 | 信号日收盘价 |
| MA20 / MA250 | 20日/250日均线 |
| 量比 | 成交量相对近期均量的比值 |
| 5日出现次数 | 近5日内该信号出现的频率（越高越可靠） |

**操作**: 点击「加入候选池」将信号股票纳入候选池进行后续跟踪。

### 3.9 组合管理 `/portfolio-mgmt`

**用途**: 实盘持仓的全生命周期管理工具，包括估值追踪、买卖决策和组合优化。

#### 标签1: 概况

关键指标一览：
- 持股数量
- 2027E 组合加权回报（基于各股的利润预测）
- 加权 PE
- Far Ahead 仓位占比（高确定性品种）
- Leading 仓位占比（成长性品种）

可视化：
- **行业分布柱状图**: 行业集中度
- **估值-增速气泡图**: X 轴=2027E 利润增速，Y 轴=合理 PE，气泡大小=仓位比例

#### 标签2: 持仓明细

核心字段说明：

| 字段 | 说明 |
|------|------|
| 分级 | Far Ahead（高确定性）/ Leading（成长型）|
| 仓位 | 当前实际仓位比例 |
| 2027E 回报 | 基于 2027 年利润预测的潜在回报 |
| 四因子 | 四因子模型调整后的综合得分 |
| 建议仓位 | 优化器输出的建议仓位 |
| 变动 | 建议仓位 - 当前仓位 |

点击任意行展开编辑，可修改：
- 利润预测（2025E/2026E/2027E）
- PE（合理/悲观/乐观）
- 净现金规模
- 股息率
- 分级和状态

#### 标签3: 买卖触发价

展示每只持仓股的实时市值和 5 个决策阈值：

| 阈值 | 含义 |
|------|------|
| 强买 | 跌到这里要重仓买入 |
| 加仓 | 当前价格适合加仓 |
| 中枢 | 合理价值中枢 |
| 减仓 | 价格偏高，开始减仓 |
| 清仓 | 价格显著高估，清仓 |

旁边显示当前信号（基于实时市值与阈值的对比）。

#### 标签4: 智能调仓（优化器）

设置约束条件后一键生成最优组合：

**可配置约束**:
- 持股数量上下限
- 行业集中度上限
- Far Ahead 仓位占比
- 现金比例
- 单股仓位上限

**输出结果**:
- 优化后关键指标卡片
- 约束满足情况（逐条显示 pass/fail）
- 推荐仓位表（代码、建议比例、预期回报、增速、股息率、估值偏离）

### 3.10 RAG 研报 `/rag`

**用途**: 用 AI 自动生成个股深度研报，节省人工撰写时间。

**三种报告类型**:

| 类型 | 内容 | 生成时间 |
|------|------|---------|
| 综合研报 | 五步法基本面 + 技术面全覆盖 | 3-5 分钟 |
| 基本面 | 五步法深度分析（行业/竞争/财务/估值/催化剂） | 2-3 分钟 |
| 技术面 | 技术指标解读 + 短期形态分析 | 1-2 分钟 |

**操作步骤**:
1. 左侧搜索框输入股票
2. 选择报告类型
3. 点击「生成研报」
4. 右侧实时显示生成进度和内容（流式输出）
5. 生成完成后可下载 .md 文件

**历史研报标签**: 查看过往生成记录，支持按股票筛选，点击展开查看完整内容。

## 四、典型使用流程

### 流程 A: 每日例行检查（15 分钟）

```
1. /data-health  -- 确认数据已更新
2. /sentiment    -- 看大盘总览，判断今日市场情绪
3. /market       -- 看宏观脉冲，确认大盘方向
4. /dashboard    -- 快速扫一眼自选股的信号变化
5. /candidate-pool -- 触发候选池监控，查看有无 RED 信号
```

### 流程 B: 行业轮动选股（30 分钟）

```
1. /industry -> ETF 乖离率 -- 找到偏低/回调的强势行业
2. /industry -> 周度排名   -- 确认该行业处于「上升」象限
3. /industry -> 行业选股   -- 按 RPS250 > 80 筛选个股
4. 一键加入候选池
5. /stock                  -- 对候选股做技术面快速扫描
```

### 流程 C: 深度研究个股（1 小时）

```
1. /stock -> 技术面分析    -- 确认技术形态
2. /stock -> 综合分析      -- 读五截面报告
3. /rag                    -- 生成一份综合研报
4. /stock -> 一页纸研究    -- 看 AI 给出的买入建议
5. /portfolio-mgmt -> 持仓明细 -- 计算建仓后的组合影响
```

### 流程 D: 组合再平衡（每月）

```
1. /portfolio-mgmt -> 概况     -- 看行业集中度和整体回报预期
2. /portfolio-mgmt -> 持仓明细 -- 更新最新利润预测
3. /portfolio-mgmt -> 买卖触发价 -- 哪些股票已超过减仓线
4. /portfolio-mgmt -> 智能调仓 -- 运行优化器，得到建议仓位
5. 对比建议仓位和实际仓位，执行调仓
```

## 五、常用指标速查

### RPS（相对价格强度）

- 含义：该股过去 N 日涨幅在全市场的分位数
- 区间：0-100，越高越强
- 参考阈值：250 日 RPS > 80 是强势股筛选常用门槛

### 对数乖离率（log_bias）

- 公式：ln(当前价) - ln(N日均价)
- 正值=偏高，负值=偏低
- 绝对值越大，均值回归压力越大

### Fear & Greed Score

- 0-25: 极度恐慌（历史上往往是买入区域）
- 25-45: 恐慌
- 45-55: 中性
- 55-75: 贪婪
- 75-100: 极度贪婪（需警惕）

### 技术信号等级

| 等级 | 标识 | 含义 |
|------|------|------|
| RED | 红色警示 | 出现明显风险信号，需要关注止损 |
| YELLOW | 黄色注意 | 形态偏弱或出现警示信号 |
| GREEN | 绿色正常 | 形态健康，无特殊风险信号 |

## 七、常见问题

**Q: 数据多久更新一次？**
A: K线数据每日收盘后（约 16:30）自动更新；技术扫描盘后运行；宏观指标和舆情数据每天定时拉取。

**Q: AI 研报的数据截止日期是什么时候？**

**Q: 候选池的「自动监控」需要手动触发吗？**
A: 目前需要在 /candidate-pool 页面点击「运行监控」按钮，后续计划改为全自动盘后任务。

**Q: RPS 数据如何解读，应该看哪个周期？**
