# 技术面信号判断规则

> 何时读：写「技术面与动量」章节（单股模式第七章 / 批量模式第五章）时。

## 判断标准

| 指标 | 信号 | 判断标准 |
|---|---|---|
| RSI（14日） | 超买 | RSI > 70 |
| RSI（14日） | 超卖 | RSI < 30 |
| RSI（14日） | 中性 | 30 ≤ RSI ≤ 70 |
| MACD | 金叉（偏多） | DIF 从下方穿越 DEA，且 MACD 柱由负转正 |
| MACD | 死叉（偏空） | DIF 从上方穿越 DEA，且 MACD 柱由正转负 |
| MACD | 顶/底背离 | 股价创新高/低但 DIF 未跟随 |
| KDJ | 超买 | K > 80 且 D > 80 |
| KDJ | 超卖 | K < 20 且 D < 20 |
| KDJ | 金叉（偏多） | K 从下方穿越 D，且处于低位（D < 50） |
| KDJ | 死叉（偏空） | K 从上方穿越 D，且处于高位（D > 50） |
| MA | 多头排列 | MA5 > MA20 > MA60，股价在 MA5 上方 |
| MA | 空头排列 | MA5 < MA20 < MA60，股价在 MA5 下方 |
| MA | 黄金交叉 | MA20 上穿 MA60 |
| MA | 死亡交叉 | MA20 下穿 MA60 |

若技术指标数据缺失，在该章节注明"技术指标数据不可用"，跳过信号解读。

## 章节内容

- 股价、20/60 日动量、波动率、换手率
- 按上表做简要技术面信号解读
